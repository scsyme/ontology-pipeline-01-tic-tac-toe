## Can the other player mark an empty square after a win?

Source suitability reviewed on 2026-11-25 for the [legal-move question](../../README.md#first-competency-question-proposed).

**Source evidence.** On page 1, the first sentence after the Computer class listing states the stopping condition: “The computer and user should alternate turns until someone wins the game or there is a draw.” On page 2, the final board in the sample game shows three Os across the bottom row and an empty square at middle right. The transcript ends with the computer winning. [MIT assignment, pp. 1–2](https://ocw.mit.edu/courses/ec-s01-internet-technology-in-local-and-global-communities-spring-2005-summer-2005/35626e9743ee128e1297030dc96d8243_MITEC_S01S05_noughtscros.pdf#page=1)

**Interpretation.** No. The win ends the sequence of turns, so the other player has no turn on which to mark the remaining square. The written instruction supports that conclusion for this assignment. The sample illustrates it on a reachable board. It contains no attempted move after the win, so it supplies no evidence about how a program would respond to such input.
